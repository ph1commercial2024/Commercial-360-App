How it works
  • The generate form (existing) stays as-is — you fill in signatories, doc type, etc.
  • Clicking "Preview & Edit" (renamed from "Generate & Print") opens this modal
  • If the RFA has saved edits, they load automatically — otherwise auto-generated content loads
  • 💾 Save writes the edited HTML for all 3 tabs to Supabase on the current PR
  • 🖨 Generate & Print assembles the full 4-page document (page 1 unedited + 3 edited pages) and opens the print window
  • A new doc_overrides JSONB column is added to purchase_requests — no other DB changes
